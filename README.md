# herdr-mods

Mods for [Herdr](https://herdr.dev). Each one is a top-level folder holding its `RECIPE.md`
(the brief to build it from scratch), a `preview.png` and the `mods/<name>/` folder itself,
laid out the way [herdr.dev/mods](https://herdr.dev/mods/) expects.

| Mod | What it does |
|---|---|
| [agent-graph](agent-graph) | The shown tab's agents as a live spawn tree, with finished ones kept by a small recorder; click to peek or resume a session. |

To add one, ask your agent: "Add the herdr mod at github.com/armedi/herdr-mods/tree/main/<name>".
